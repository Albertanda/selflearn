# MD-R1：模型发现与选择管理

本目录是交给 DeepSeek Harness 的一个完整执行阶段。以 Chatbox 式设置页管理为基础，增加当前供应商首次自动获取和服务端缓存。七类模型共用入口；搜索服务不属于模型目录。

执行顺序：`START_MD_R1.txt` → `CONTRACTS.md` → `TASKS.json` → `EXPLORATION.md` → `ACCEPTANCE.md`。
小单元用于编码和自测；完成整个阶段后只汇报一次，不逐卡等待批准。

本阶段不增加推理协议、不批量验证模型、不做 Hermes 式全局后台发现、不改变管理员授权体系。
现有阿里云 ASR 已实测可用，真实默认是北京地域 `qwen3-asr-flash`；不得覆盖其配置或回退代码。

预期用户流程：

1. 配置供应商连接并保存；当前配置首次获取候选目录。
2. 在“查询模型”中搜索、筛选、勾选；确认后加入设置草稿。
3. 保存后进入相应模型列表。LLM 可以单独切换“在聊天选择器中显示”。
4. 刷新只更新候选目录，不删除模型、不改默认项、不重置显示偏好。
